# 📊 Tecboard

Landing page desenvolvida para o Tecboard, uma plataforma de monitoramento em tempo real com alertas inteligentes, feita para que aplicações nunca saiam do ar sem o usuário saber.

Este projeto foi meu primeiro trabalho como desenvolvedor front-end, com foco em transformar um layout do Figma em uma página real, responsiva e fiel ao design proposto.

## 🚀 Tecnologias utilizadas

- **HTML5** — estruturação semântica do conteúdo
- **CSS3** — estilização e responsividade (Flexbox, media queries)
- **Git & GitHub** — versionamento de código

## 🎨 Layout

O layout foi desenvolvido por um(a) designer e disponibilizado no Figma. Meu trabalho foi codificar essa interface fielmente, cuidando de espaçamentos, tipografia e cores.

🔗 [Acesse o layout no Figma](https://www.figma.com/design/ROPVwjQDkY4WmmepvPrtjg/Tecboard-%7C-Landing-page--Community---cópia-?node-id=0-1)

## 📱 Responsividade

A página foi construída para se adaptar a diferentes tamanhos de tela, com breakpoints para:

- 🖥️ Desktop
- 📱 Tablet (até 768px)
- 📱 Mobile (até 375px)

## 💡 O que eu aprendi

- Como transformar um design do Figma em código HTML/CSS fiel ao protótipo
- Uso de media queries para criar uma experiência responsiva de verdade
- Boas práticas de organização de código CSS
- Fluxo de versionamento de projetos com Git e GitHub
